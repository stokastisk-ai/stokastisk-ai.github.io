# Stokastisk documentation site

Source of the documentation website (repository `stokastisk-ai/stokastisk-ai.github.io`, formerly `stokastisk-docs`) for [Stokastisk](https://github.com/stokastisk-ai/stokastisk), an independent open-source Python SDK for vLLM inference on Kaggle's dual NVIDIA Tesla T4 GPUs. Built with [Great Docs](https://github.com/posit-dev/great-docs) and [Quarto](https://quarto.org/); canonical URL <https://stokastisk-ai.github.io/>.

The SDK repository stays authoritative for code, release metadata and Kaggle evidence. This repository owns the site configuration, the hand-written guide, the validation scripts and the deployment workflow. The API reference is generated by static analysis (no vLLM, torch or CUDA is installed or imported) from the SDK commit recorded in `SOURCE.lock.json`.

```bash
python3.13 -m pip install --user --no-cache-dir -r requirements-docs.txt   # Quarto 1.11.9 standalone is also required
scripts/build_site.sh --validate [../Project-Stokastisk]                    # stage pinned SDK, build, post-process, validate -> _site/
```

See `deliverables/DEPLOYMENT.md` for deployment, `deliverables/GOOGLE-SEARCH-CONSOLE.md` for search setup and `reports/` for the latest audit results.
